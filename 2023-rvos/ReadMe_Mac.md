# MacOS Riscv 安裝

---
1. install crossed compiler(GCC)
```zsh
$ sudo brew install gcc-riscv64-unknown-elf
```
2. install some tools
```zsh
$ brew install gcc make perl dkms git
```
3. install qemu
```zsh
$ brew install qemu
```
4. install gdb-multiarch
* homebrew gdb-multiarch已停用，該作者表示可直接安裝hombrew gdb
```zsh
$ brew tap 
```
